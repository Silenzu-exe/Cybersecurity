# Cyber Security


Personal notes, reference material, and practice code from my ongoing cybersecurity learning journey. Written in Obsidian, pushed here for backup and reference as I work through networking, Linux, Python, tools, and offensive security fundamentals.

This isn't a polished course archive, it's a working log of what I'm learning, in the order I'm learning it.

## Notes

**Foundation** — how a computer works, a numbered progression through Linux (navigation, file operations, permissions, ownership, search, compression, user/group management, redirection, networking commands) plus a Termux guide, and networking fundamentals (OSI/TCP-IP, protocols, IP addressing and subnetting, DNS, HTTP/HTTPS, ports and services, Nmap and recon, packet analysis, network attacks, firewalls/IDS/IPS, wireless security).

**Ethical Hacking** — the 5 stages of ethical hacking, plus per-target exploitation guides (recon through privilege escalation) as I work through practice VMs.

**Roadmap** — the overall learning plan: a checklist tracking progress, the long term roadmap, and a running pentest journey guide with a weekly schedule and daily log.

## Python

Practice scripts covering the language fundamentals in order (variables through OOP), a Black Hat Python section with notes and code kept together by topic, and a folder of extra self experiments (like two way threaded netcat style communication).

## Practice

OverTheWire Bandit progress log, a bash IP sweep script, and a growing set of exploitation guides for practice VMs (VulnHub/CTF style boxes).

## Tools

Notes organized by category (reconnaissance, scanning and enumeration, password attacks, web app testing, networking utilities, cryptography), plus working scripts picked up along the way such as Sublist3r for subdomain enumeration.

## Why public

Mainly for my own reference and backup, but the notes might help someone else working through the same material. Feedback and corrections welcome.

## Disclaimer

All notes, scripts, and techniques here are for educational purposes only, developed against legal practice environments (CTF platforms, home lab, intentionally vulnerable machines). Nothing here is intended for use against systems without explicit permission.
