# Cyber Security

Personal notes, reference material, and practice code from my ongoing cybersecurity learning journey. Written in Obsidian, pushed here for backup and reference as I work through networking, Linux, Python, and offensive security fundamentals.

This isn't a polished course archive — it's a working log of what I'm learning, in the order I'm learning it.

## Structure

```
Cyber Security/
├── Books/        # reference texts (Black Hat Python, Hacking: The Art of Exploitation,
│                 #   Linux Basics for Hackers, Web Application Hacker's Handbook)
├── Notes/
│   ├── Linux/        # command-line fundamentals, numbered as a progression
│   ├── Networking/   # OSI/TCP-IP, protocols, subnetting, ports, nmap, packet analysis,
│   │                 #   attacks, firewalls/IDS/IPS, wireless security
│   └── Roadmap/      # learning roadmap, checklist, monthly goals, home lab setup
├── Python/       # Python fundamentals practice, topic by topic (variables through dicts)
└── tools/        # scripts, cheat sheets, and recon notes (nmap sweep script, Hydra cheatsheet)
```

## Notes

**Linux** — a numbered progression from navigation and file operations through permissions, ownership, search, compression, user/group management, redirection, and networking commands, plus an OverTheWire Bandit log and a Termux guide.

**Networking** — OSI/TCP-IP models, protocols, IP addressing and subnetting, ports and services, Nmap and recon, packet analysis, network attacks, firewalls/IDS/IPS, and wireless security.

**Roadmap** — the overall learning plan: a checklist tracking progress, the long-term roadmap, first-month goals, monthly goals, and a home lab setup guide.

## Python

Practice scripts covering the language fundamentals in order: variables, strings, booleans, operators, lists, tuples, sets, and dictionaries — plus reference PDFs.

## Tools

Working scripts and cheat sheets picked up along the way (e.g. an IP sweep script, a Hydra cheat sheet), used during recon and practice.

## Why public

Mainly for my own reference and backup, but the notes might help someone else working through the same material. Feedback and corrections welcome.

## Disclaimer

All notes, scripts, and techniques here are for educational purposes only, developed against legal practice environments (CTF platforms, home lab, intentionally vulnerable machines). Nothing here is intended for use against systems without explicit permission.

## About

BSc CSIT student working through cybersecurity fundamentals and offensive security practice alongside coursework. Notes are updated as I progress — expect gaps and works-in-progress.
