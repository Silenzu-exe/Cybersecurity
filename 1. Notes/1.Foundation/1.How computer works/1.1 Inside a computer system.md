>How a computer works, how an OS works

Nearly every computer system that you can think of includes, in one way or another, the same building blocks. Each part has its own job, and together they make the computer work. Let's have a look at each of these building blocks.

## What happens when you press the power button

![[Pasted image 20260805192321.png]]

**Step 1: Press the Power Button**
When we press the power button on our computer system, a signal is sent to the Power Supply Unit (PSU) to allow power to flow. Imagine our body being powered off when we sleep. Once we wake up and receive oxygen, our body starts pumping blood and boots up.

**Step 2: Firmware starts**
Continuing our analogy from step 1, once the body has started up, our core components are up and running, but our brain is not yet conscious. Like our bodies, a computer system contains firmware that allows all its components to start up. The central system that manages this is called the Unified Extensible Firmware Interface (UEFI).

> [!note] BIOS vs UEFI
> We will often see the term BIOS (Basic Input/Output System) mentioned instead of UEFI. BIOS does the same job as UEFI, but has mainly been replaced by UEFI on modern systems. UEFI is faster, supports larger drives, and has a more modern interface, but you will still see BIOS used as a general/informal term for firmware even on UEFI systems.

**Step 3: Power-On Self Test**
Now that our body is up and running, it is time to test if everything is functioning as it should. If something isn't, there will be some alarm signals. One of the routines that the UEFI loads is the Power-On Self Test (POST), which tests if every required component is present, configured correctly, and functioning.

**Step 4: Select Boot Device**
Once our body is up and running, configured correctly and fully functional, our system searches for the location of our bootup routine to start our consciousness. In our computer system the UEFI holds an ordered list, called the boot order, which prioritizes which device to look at first for the boot up routine of the Operating System (for example, hard disk before USB, or the other way around if you're booting from a live USB).

**Step 5: Initiate Bootloader**
Now that our system knows where the part of our brain that holds consciousness is located, it initiates the "load routine" to start it. Our computer systems follow a similar process: on the selected boot device, the bootloader is initiated. This bootloader transfers the Operating System from the selected boot device into Random Access Memory (RAM). Once the OS is transferred, the bootloader hands over control from itself to the Operating System, which then takes over managing the different components of the system.

## Quick Recap

* PSU receives power first
* UEFI/BIOS wakes up and initializes hardware
* POST checks everything is functioning
* UEFI/BIOS checks the boot order and picks a boot device
* Bootloader loads the OS into RAM and hands off control
